## What Changed in v2.1.0

1. **Places system restored** -- memories route to spatial places (WIP, Board, Ref, etc.) via `knowledge_edges`. Walking, context injection, and place-aware retrieval all functional.
2. **Knowledge schema v2** -- `knowledge` + `knowledge_edges` tables replace old `memories` + `memory_places` + `entity_relations`. Backward-compatible migration runs automatically.
3. **Consolidation pipeline** -- merge similar memories, LLM-powered consolidation, automatic dedup.
4. **Team memory** -- personal + team scope with invitations and sharing.
5. **Edit proposals** -- propose, preview, approve, reject, correct with undo.
6. **Scoring v2** -- composite ranking with graph boost, recency, importance, MMR, query expansion, temporal validity.
7. **19 MCP tools** -- up from 16 in v2.0.0.

## Known Limitations

1. **Small RAG sample** -- 20 queries gives a ~76-99% 95% Wilson confidence interval. Expanded to 104 queries (v2 dataset) for higher statistical power. Full run pending.
2. **Single model** -- Results are with Laguna XS 2.1 only. Cross-model validation planned.
3. **Negation queries** -- Hit@1 of 0.625 is the weakest retrieval category. Negation-aware scoring is a known challenge.
4. **LoCoMo partial scores** -- 63% partial credit indicates the model often gets close but misses details. Higher-capacity models expected to improve full-correct rate.
